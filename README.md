### 📂 Projetos em Destaque (Foco em Solução de Problemas)

#### 🏗️ [LotePIM](https://github.com/LptLeo/LotePIM) - Sistema de Gestão Industrial
**Plataforma de gestão industrial full-stack** projetada para substituir controles manuais por planilhas. O sistema digitaliza e automatiza o ciclo de vida completo de lotes de produção — da abertura à inspeção final — entregando rastreabilidade total e métricas em tempo real.
* **Impacto:** Eliminação de gargalos fabris com Dashboard Executivo, progressão automática de status e Sistema de Alertas Inteligentes.
* **Stack & Práticas:** Angular 21, Tailwind CSS 4, Node.js (Express 5), TypeORM, PostgreSQL e Docker. Implementação de *Paginação Server-Side* e *Polling Real-time* otimizado.

#### 📦 [Mundo Geek](https://github.com/LptLeo/Mundo-Geek) - API de Gerenciamento de Inventário
**API robusta e escalável** desenvolvida para suprir a necessidade real de controle de estoque de uma loja de cultura pop. O sistema organiza estrategicamente produtos por categorias, garantindo eficiência operacional e alta confiabilidade dos dados.
* **Impacto:** Substituição do controle manual, integridade de dados através de relacionamentos relacionais (1:N) e arquitetura padronizada para futuras integrações.
* **Stack & Práticas:** TypeScript, Express, TypeORM, PostgreSQL e Zod. Arquitetura estruturada com clara divisão de responsabilidades (Middlewares, Controllers, Services e Entities).

#### 🌍 [Monitoramento Ambiental](https://github.com/LptLeo/Sistema-de-Monitoramento-Ambiental) - API de Entidades
**Solução técnica para gestão de telemetria** focada no gerenciamento de dados de estações de monitoramento ambiental. Permite o acompanhamento preciso de variáveis geográficas e de sensores em tempo real.
* **Impacto:** Registro seguro de telemetria e consistência geográfica com validação rigorosa de coordenadas (latitude/longitude) para relatórios técnicos.
* **Stack & Práticas:** Node.js, TypeScript e Express. Uso de Middlewares customizados para interceptação e validação de rotas, mantendo uma divisão clara da lógica de negócios.
